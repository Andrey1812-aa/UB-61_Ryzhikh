## Дополнительные объяснения и ответы на вопросы

* **Почему для учебной записи подходит словарь:**
В одной записи нужно хранить разные свойства — название курса, количество часов и отметку о прохождении. В словаре у каждого свойства есть свой ключ, например `hours`. Поэтому значение легко найти по названию ключа, изменить или добавить новое поле, не запоминая его номер в списке.

* **Для чего нужен метод `.get()`:**
Он помогает получить значение по ключу, даже если такого ключа пока нет. Например, `counts.get(word, 0)` возвращает количество уже найденных повторений слова или `0`, если слово встретилось впервые. Затем к результату добавляется единица. При обычном обращении `counts[word]` к отсутствующему ключу возникла бы ошибка `KeyError`.

* **Зачем при работе с множествами используется `sorted()`:**
Множество хранит только уникальные элементы, но порядок вывода у него не гарантирован. Функция `sorted()` превращает результат в список с понятным алфавитным порядком. Благодаря этому вывод одинаково выглядит при разных запусках и его удобно проверять тестами.

* **Чем отличаются список, множество и кортеж:**
Список подходит для упорядоченного набора, в котором могут быть повторы. Множество полезно, когда нужно найти общие темы или собрать все уникальные значения. Кортеж подходит для фиксированной пары, например названия курса и количества часов: его элементы после создания нельзя заменить.

* **Как выполняется индивидуальный вариант №8:**
Маршруты хранятся в списке словарей с ключами `title`, `category` и `amount`. Поле `amount` — длина маршрута в целых километрах. Функция `totals_by_category` проходит по всем маршрутам и складывает длины одинаковых категорий. Функция `titles_in_category` выбирает названия нужной категории, не переставляя их. Если категории нет, возвращается пустой список. Для сводки категории сортируются по алфавиту.

* **Как проверялась сохранность исходных данных:**
Перед вызовом функций создаётся пустой список, а затем циклом `for` в него добавляются копии словарей через `record.copy()`. После подсчёта сумм и поиска названий исходный список сравнивается с копией. Это показывает, что функции только читают записи и не меняют их поля.

* **Как работает сортировка в дополнительном задании:**
Функция получает пары вида `(category, total)`. В отдельной функции `sort_key` из пары берутся категория и сумма. Она возвращает `(-total, category)`: поэтому сначала идут большие суммы. При равенстве сумм сортировка идёт по названию категории.
