## Структура лабораторной работы

В данной лабораторной работе (`Lab_3`) представлены следующие файлы с исходным кодом:

1. `minimum.py` — поиск минимального из трех целых чисел с использованием ветвлений (`if`/`elif`/`else`).

2. `calculator.py` — простой калькулятор для вещественных чисел с поддержкой операций `+`, `-`, `*`, `/` и обработкой ошибок.

3. `point.py` — проверка принадлежности точки с координатами `(x, y)` прямоугольнику (`0 <= x <= 5` и `0 <= y <= 3`).

4. `variant8.py` — определение категории заполненности группы по введенному значению от 0 до 100 (индивидуальный вариант №8).

## Доп объяснения и ответы на вопросы:

* **Выбор `and` / `or`:** Логический оператор and используется тогда, когда требуется одновременное выполнение всех указанных условий (например, при проверке, что точка попадает в диапазон по обеим осям одновременно: 0 <= x <= 5 and 0 <= y <= 3). Оператор or применяется в ситуациях, когда достаточно выполнения хотя бы одного из условий (к примеру, при проверке выхода введенных данных за границы допустимого интервала).

* **Порядок ветвей в условных операторах:** Условные конструкции if-elif-else проверяются интерпретатором поочерёдно сверху вниз, и сработает код только той первой ветки, условие которой оказалось истинным. Из-за этого отсечение критических ошибок или специфических граничных вариантов всегда располагают в самом начале, а более общие случаи оставляют для веток elif и else.

* **Поведение при равенстве значений:** Грамотное комбинирование строгих (<, >) и нестрогих (<=, >=) знаков сравнения обеспечивает корректный охват пороговых значений ровно один раз. Это гарантирует, что при совпадении с краем диапазона значение попадает строго в один нужный интервал и не вызывается никаких пересечений.
