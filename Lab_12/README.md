## Структура лабораторной работы

В данной лабораторной работе (`Lab_12`) представлены следующие файлы:

1. `main.py` — консольное меню, ввод данных, вывод маршрутов и статистики.
2. `logic.py` — функции проверки, добавления, поиска, изменения статуса, удаления и статистики.
3. `storage.py` — чтение и сохранение записей в JSON.
4. `test_logic.py` — автоматические проверки функций обработки маршрутов.
5. `test_storage.py` — автоматические проверки хранения данных и ошибок чтения.
6. `data.json` — три исходных туристических маршрута.

## Инструкция по запуску программ

Для запуска необходим Python 3 (рекомендуется версия 3.13 или новее).

1. Откройте терминал в папке `Lab_12`.

2. Запустите автоматические тесты:

   ```bash
   python test_logic.py
   python test_storage.py
   ```

3. Запустите основную программу:

   ```bash
   python main.py
   ```

(В Windows вместо `python` можно использовать `py`, а в некоторых системах — `python3`.)

После запуска `main.py` выбирается команда от 1 до 8: показать записи, добавить, найти, изменить статус, удалить, показать статистику, сохранить или выйти. Для проверки исходных данных выберите `6`, затем `8` и `нет`. При добавлении вводятся название, категория и расстояние в целых километрах.

## Дополнительные объяснения и ответы на вопросы

- **Зачем программа разделена на модули:** В `main.py` находится взаимодействие с пользователем, в `logic.py` — обработка записей, в `storage.py` — файлы. Так вычисления можно проверять отдельно от меню.

- **Как хранится маршрут:** Каждый маршрут — словарь с ключами `id`, `title`, `category`, `amount` и `completed`. Все маршруты находятся в списке. Расстояние хранится целым числом, статус — логическим значением.

- **Как создаётся ID:** Для непустого списка находится наибольший существующий ID через `max()` и прибавляется единица. Для пустого списка используется 1. После удаления другие записи не перенумеровываются.

- **Как работает поиск:** Название и поисковая строка приводятся к одному регистру, после чего проверяется вхождение подстроки. Если совпадений нет, возвращается пустой список.

- **Как считается статистика:** Программа проходит по записям, считает пройденные маршруты и суммирует расстояния. В отдельном словаре накапливается длина для каждой категории. В исходном примере всего три маршрута, один пройден, общая длина 18 км.

- **Как добавить фильтр:** В логике можно создать функцию, которая проходит по списку и добавляет в результат только маршруты с нужным условием, например `record['completed'] == True`. Затем результат передаётся функции вывода записей.

- **Как изменить вывод статистики:** В `show_statistics` можно добавить вывод нового показателя. Если его ещё нет в словаре результата, сначала нужно рассчитать его в `statistics`.

- **Как сохраняются данные:** Список словарей записывается через `json.dump`. При следующем запуске `json.load` восстанавливает его, после чего проверяется структура записей.

- **Что происходит при повреждении файла:** Программа сообщает об ошибке и прекращает запуск, чтобы не перезаписать повреждённый файл пустым списком.
