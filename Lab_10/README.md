## Структура лабораторной работы

В данной лабораторной работе (`Lab_10`) представлены следующие файлы:

1. `main.py` — ввод положительного числа, чтение матрицы и создание отчёта с обработкой ошибок.
2. `files_lab.py` — функции `read_matrix` и `selected_sum` для чтения матрицы и выполнения индивидуального варианта.
3. `table.py` — модуль из ЛР №9; используются `row_sums` и `column_sums`.
4. `test_files.py` — автоматические проверки чтения, вычислений и ошибок с помощью `assert`.
5. `matrix.txt` — исходная матрица размером 2×3.
6. `report.txt` — результаты вычислений.

## Инструкция по запуску программ

Для запуска необходим Python 3 (рекомендуется версия 3.13 или новее).

1. Откройте терминал в папке `Lab_10`.

2. Запустите автоматические тесты:

   ```bash
   python test_files.py
   ```

3. Запустите основную программу:

   ```bash
   python main.py
   ```

(В Windows вместо `python` можно использовать `py`, а в некоторых системах — `python3`.)

При запуске `main.py` сначала вводится положительное целое число, например `3`. Затем программа читает `matrix.txt`: первая строка содержит размеры, следующие строки — целые числа через пробел. Результаты записываются в `report.txt`.

## Дополнительные объяснения и ответы на вопросы

- **Как выполняется вариант №8:** Функция `selected_sum` складывает числа первой строки. Для пустой матрицы возвращается ноль. Остальные строки в расчёте варианта не участвуют.

- **Зачем проверять размеры матрицы:** Если в заголовке указаны два ряда и три столбца, программа должна прочитать ровно два ряда по три числа. Иначе вычисление сумм может дать неправильный результат.

- **Чем отличаются режимы открытия файла:** Режим `r` открывает файл для чтения, `w` перезаписывает его, а `a` добавляет данные в конец. Кодировка UTF-8 нужна для корректной работы с русским текстом.

- **Зачем используется with:** После окончания блока файл закрывается автоматически, даже если внутри возникло исключение.

- **Как обрабатываются ошибки:** `try` содержит действия, при которых возможна ошибка, а `except` позволяет обработать её. Например, `ValueError` возникает при неверном формате числа, а `FileNotFoundError` — при отсутствии файла.

- **Почему отчёт не открывается сразу:** Сначала проверяется матрица и выполняются расчёты. Только после этого открывается отчёт на запись. Поэтому ошибка чтения не уничтожает предыдущий отчёт.

- **Зачем нужен table.py:** Модуль перенесён из девятой работы, чтобы повторно использовать готовые функции сумм строк и столбцов.
