## Дополнительные объяснения и ответы на вопросы

- Режим `r` читает, `w` перезаписывает, `a` дописывает.
- `with` закрывает файл автоматически. `ValueError` обозначает неправильные данные, `OSError` — проблемы файловой системы, `FileNotFoundError` — отсутствие файла.
- Отчёт открывается только после проверки и расчётов; поэтому некорректный вход не уничтожает старый отчёт.
- `table.py` перенесён из папки Lab_9; используются функции row_sums и column_sums.
