## Структура лабораторной работы

В данной лабораторной работе (`Lab_4`) представлены следующие файлы с исходным кодом:

1. `range_numbers.py` — вывод чисел от `a` до `b` включительно по возрастанию, убыванию или одного числа при равенстве.

2. `statistics.py` — расчет суммы, числа положительных значений и максимума для введенных `n` целых чисел.

3. `positive_input.py` — повторный запрос целого числа до получения положительного, с выводом квадрата и количества отклонённых попыток.

4. `variant8.py` — нахождение количества и суммы ненулевых значений в потоке из `n` целых чисел, значение модуля которых строго превышает `5`.

5. `Dop.py` — проверка целого числа `n >= 2` на простоту путем перебора делителей до квадратного корня из `n`.

## Доп объяснения и ответы на вопросы:

* **Выбор `for` и `while`:** Цикл `for` берут, когда заранее известно количество итераций или есть готовый набор элементов (к примеру, диапазон чисел `range`). Цикл `while` запускают, когда число повторений неизвестно заранее и работу нужно продолжать до тех пор, пока выполняется заданное логическое условие.

* **Завершение цикла:** Чтобы цикл `while` не стал бесконечным, переменная в его условии должна обновляться в теле цикла, либо остановка должна происходить с помощью оператора `break` при наступлении определенного события.

* **Накопители и счётчики:** При суммировании элементов от 1 до 4 переменная-накопитель `total` стартует с 0. На каждом шаге к ней прибавляется текущее число, поэтому значения до прохода итерации равны `0, 1, 3, 6`, а сразу после её выполнения — `1, 3, 6, 10`.

* **Особенность `range(a, b)`:** Стандартная функция range генерирует числа с шагом `1` и не захватывает само значение `b`. Если первое число больше второго (`a > b`), вызов `range(a, b)` даст пустой набор значений, из-за чего для обратного отсчета нужно обязательно указывать отрицательный шаг и обрабатывать этот случай отдельно в коде.
