## Структура лабораторной работы
В данной лабораторной работе (`Lab_1`) представлены следующие файлы с исходным кодом:
1. `hello.py` — вывод строк.
2. `profile.py` — карточка студента с расчетом возраста через 4 года и времени подготовки.
3. `workload.py` — расчет учебной нагрузки по двум предметам и остатка свободного времени.
4. `debug.py` — исправление ошибок (типы данных, деление, операции со строками).
5. `swap.py` — обмен значениями двух переменных (названий аудиторий) с использованием временной переменной.
6. `variant8.py` — расчет стоимости заказа (индивидуальный вариант № 8) с учетом скидки и сдачи.

## Дополнительные объяснения

* **Различие строки и числа:** тип str представляет собой текстовый формат данных, состоящий из набора символов. При «сложении» двух строк происходят их объединение и сцепление в один общий текст, а умножение строки на целое число дублирует её указанное количество раз. В свою очередь, числа (int для целых и float для дробных) предназначены для стандартных арифметических вычислений.
* **Порядок вычислений:** вычисление выражений выполняется с соблюдением общепринятых математических приоритетов — операции умножения и деления выполняются раньше, чем сложение и вычитание. Для принудительной смены последовательности шагов применяются круглые скобки (), задающие явный порядок действий.
* **Назначение временной переменной:** дополнительная переменная требуется для того, чтобы случайно не стереть данные. Так как прямое копирование a = b моментально уничтожает исходное значение переменной a, его предварительно помещают во временный «буфер» (переменную temp), что позволяет корректно переписать значения без их потери.
